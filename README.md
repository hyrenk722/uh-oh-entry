> Guessing

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes the word to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`) with no network access; two runs write
identical bytes.
